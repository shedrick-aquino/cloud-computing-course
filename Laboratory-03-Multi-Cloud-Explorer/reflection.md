# Mission Reflection

Among the three cloud platforms, **Google Cloud** impressed me the most because of its strong focus on artificial intelligence, data, and Kubernetes. While AWS provides a very broad range of services and Azure has clear advantages for organizations already using Microsoft products, Google Cloud's combination of Vertex AI and Google Kubernetes Engine stood out to me. Google documents GKE as its managed Kubernetes service and explains that Kubernetes was originally developed by Google based on experience with large-scale container workloads.

I also learned that AWS, Azure, and GCP are similar in their basic service categories. All three provide virtual machines, object storage, virtual networking, identity and access management, managed SQL databases, and managed Kubernetes platforms. The names are different, but the main cloud-computing goals are similar: provide scalable infrastructure and services without requiring organizations to own every physical server.

This activity showed me that choosing a cloud provider should depend on **business requirements**, not only popularity. A university already using Microsoft 365 and Windows technologies may benefit from Azure and Microsoft Entra ID, while an AI research company may prefer Google Cloud's AI and machine-learning platform. A global e-commerce company may prioritize automatic scaling, resilient multi-zone design, DNS, and global content delivery.

Acting as a Cloud Solutions Consultant helped me connect technical services to real organizational needs. Instead of simply memorizing product names, I had to think about cost, compatibility, scalability, availability, identity, and workload type. I also improved my GitHub Cloud Computing Portfolio by adding structured Markdown research, comparison tables, client recommendations, citations, screenshots, and a documented Linux investigation. The repository now demonstrates not only cloud concepts but also my ability to organize technical evidence and explain why a particular solution fits a specific scenario.
